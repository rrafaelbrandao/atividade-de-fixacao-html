HTML e CSS - Entenda de uma vez

HTML

O que significa HTML ?

HTML significa Hyper Text Markup Language, que traduzindo é Linguagem de Marcação de Hipertexto.

Ela é usada no mundo todo como uma linguagem padrão na estruturação e organização de sites na World Wide Web.

Ela é responsável por:

  • Estuturar o conteúdo de uma página
  • Organizar e dar Sentido a toda página através das tags
  • Conectar a página a outras através de hiperlinks

O que são TAGS em HTML ?

As tags são importantes marcações que vão informar ao navegador como estruturar e exibir a página.


Exemplos:

  • <p> Olá,mundo !</p> | Serve para definir e estruturar um parágrafo
  • <h1>Título Principal</h1> | Serve para definir o título principal da página
  • <a href="#">Clique aqui</a> | Serve para criar links para outras páginas ou arquivos
  • <strong>Texto em Destaque</strong> | Serve para dar forte importância ao texto, deixando-o em negrito

Como definir uma tag no HTML ?

Para definir uma tag no html, você deve seguir a seguinte estrutura:

  • São abertas por < e >
  • Precisam ser especificadas dentro desse sinal.
    Exemplo: < "nome da tag" >
  • Algumas tags precisam ser fechadas.
    A estrutura funciona assim:
    < "nome da tag" >"conteúdo da tag" < "nome da tag /" >

O que são atributos no HTML ?

Os atributos vão ser as informações adicionais colocadas na tag que vão modificar e definir as características e comportamentos de um elemento.

Eles podem ser globias ou específicos de cada tag.

Funcionamento:

  • Ficam na tag de início
    Ex: <a href="">Texto exibido<a/>
  • Tem um nome e seu valor é atribuido por um sinal de =
    Ex: <a href="">Texto exibido<a/>
  • O valor deve ser definido entre aspas simples ou duplas
    Ex: <a href="https:....">Texto exibido<a/>

Qual a estrutura básica do HTML ?

Uma estrutura básica de um documento HTML vai consistir de um modelo padrão com as tags essenciais para que o navegador leia e exiba a página corretamente

                    
                        <!DOCTYPE html>
                        <html lang="pt-br">
                        <head>
                            <title>Exemplo</title>
                        </head>
                        <body>
                            <h1>Meu Código</h1>
                        </body>
                        </html>
  • <!DOCTYPE html>: Informa ao navegador que o documento é do tipo HTML5.
  • <html lang="pt-br">: É o elemento raiz que engloba todo o conteúdo da página. O atributo lang="pt-br" define o idioma principal do site.
  • <head>: Guarda as configurações e os metadados da página (como o conjunto de caracteres e o tamanho da tela), que não aparecem diretamente para o usuário.
  • <title>: Define o título que aparece na aba do navegador.
  • <body>: É o corpo do documento, onde fica todo o conteúdo visível, como textos, imagens e links

Exemplificação e explicação de algumas tags HTML

Agora, veremos uma tabela com as principais tags HTML e quais são as suas funções na estruturação da página

TAG FUNÇÃO
<html> É a tag raiz de um documento HTML. Ela informa ao navegador que todo conteúdo presente dentro dela é um código HTML da poágina e deve ser lido como tal
<head> Ela armazena metadados e informações fundamentais para o navegador, incluindo configurações, instruções técnicas e conexões com arquivos externos, definindo como a página deve funcionar.
<meta> Elas são pequenos pacotes de informação que vão armazenar alguns importntes detalhes técnicos sobre a página
<title> Ela vai definir o título oficial da página. É nela que os usuários e buscadores vão identificar o seu site
<body> Ela armazena tudo que o usuário consegue ver, ler e interagir na página. É a interface física da página que está acessível ao usuário
<h1> Ela vai indicar qual é o assunto mais importante acerca do seu texto/página, assemelhando se ao título de um livro, por exemplo. Nota: é muito importante haja apenas uma por página
<ol> Ela é utilizada para criar listas ordenadas, apresentando os itens em uma sequência lógica ou numérica.
<li> É a tag responsável por definir cada um dos elementos que vai dentro de uma lista. Ela não trabalha sozinha, é uma tag auxiliar da <ol>(para listas ordenadas) e <ul>(para listas não ordenadas)

CSS

O que significa CSS ?

CSS significa Cascading Style Sheets, que traduzindo é Folhas de Estilo em Cascata.

Ela é uma linguagem de esilo usada para definir a aparência visual de páginas web criadas com HTML.

Ela é responsável por:

  • Design e Cores: vai definir as cores, tons, sombras e imagens dos elementos;
  • Tipografia: vai definir as fontes, tamanhos e design das letras;
  • Layout: vai organizar e harmonizar os diferentes elementos da página;
  • Responsividade: fará com que a página se adapte e se comporte de maneira automática a tela de celulares, tablets e etc

O que é um SELETOR em CSS ?

Um seletor em css é um padrão ou símbolo utlizado para que o CSS possa encontrar e aplicar o estilo definido para um ou vários elementos.

Exemplo:

  • p {
    font-size: 16px;
    }
  • .classe-exemplo {
    color: blue;
    }
  • #id-exemplo {
    background-color: yellow;
    }
  • button:hover {
    cursor: pointer;
    }

Como definir e quais são os Seletores em CSS ?

Para definir um seletor no CSS, você deve escrever o seletor para [padrão/elemento] desejado antes das chaves {} daquele elemento

Logo após, todos os estilos, valores e propriedades do elemento deverão estar dentro das {}

Exemplos:

  • Seletor de Tag(tag): Vai identificar o elemento pelo nome da tag
    • p {
      font-size: 16px;
      background-color: black;
      }
  • Seletor de Classe(.): Vai escolher os elementos que possuem um atributo de classe específico
    • .titulo-principal {
      font-size: 32px;
      color: white;
      }
  • Seletor de Id(#): Vai escolher um elemento único com base no seu atributo id
    • #secao-sobre {
      font-size: 40px;
      background-color: red;
      }
  • Seletor Universal(*): Vai selecionar e aplicar um estilo atodos os elementos da página
    • * {
      margin: 0px;
      padding: 0px;
      }
  • Pseudoclasses(:): Vai dar ou alterar o (estado/comportamento) de um elemento conforme um evento específico
    • p {
      font-size: 16px;
      background-color: black;
      }

Qual a estrutura basica em CSS ?

A estrutura básica do CSS vai consistir em um seletor seguido por um bloco de declarações delimitadas por chaves {} 

                    
                        seletor {
                            propriedade: valor;
                            propriedade: valor;
                            .
                            .
                            .
                        }
  • Seletor: Aponta para o elemento HTML que você deseja estilizar (como h1, p, ou uma classe como .botao).
  • Bloco de declaração: Fica entre chaves {} e guarda uma ou mais regras de estilo.
  • Propriedade: O aspecto visual que você deseja mudar (por exemplo, color para cor do texto ou font-size para tamanho da fonte).
  • Dois-pontos (:): Separa o nome da propriedade do seu respectivo valor.
  • Valor: A configuração exata aplicada à propriedade (como red ou 16px).
  • Ponto e vírgula (;): Finaliza cada declaração individual, separando-a da próxima.

Qual a hierarquia de prioridade nos seletores em CSS ?

A prioridade no CSS (chamada de especificidade e cascata) segue uma ordem do mais forte para o mais fraco:

Ordem de priorodade(maior para o menor):

  1. !important: Adicionado a uma regra, ele tem a força máxima e vence qualquer outra especificidade normal.
  2. Estilos Inline: Estilos escritos diretamente no elemento HTML.
  3. IDs (#id):Seletores de identificador único.
  4. Classes, Atributos e Pseudo-classes (.classe, [type="text"], :hover)
  5. Elementos/Tags e Pseudo-elementos (p, div, ::before).
  6. Seletor Universal (*) e Combinadores: Possuem peso zero ou são ignorados no cálculo de empate.

Observação:

Se dois seletores têm exatamente o mesmo nível de especificidade, o último declarado no código CSS é o que vale, obedecendo à regra da cascata.
