# 📚 Entendendo HTML e CSS

Este projeto é um guia interativo e educativo sobre as tecnologias fundamentais da Web: **HTML5** e **CSS3**. Ele foi desenvolvido com o intuito de aplicar na prática os conceitos teóricos de estrutura, semântica, seleção e estilização de elementos web.

## 🚀 Sobre o Projeto

O site funciona como uma página didática dividida em duas seções principais:

1. **HTML (HyperText Markup Language):** Explicação sobre estrutura, conceitos de tags, atributos, hierarquia de elementos e tabelas explicativas.
2. **CSS (Cascading Style Sheets):** Detalhamento sobre seletores, especificidade/hierarquia, regras de sintaxe e principais propriedades de estilização.

Todo o projeto utiliza marcação semântica e recursos visuais interativos em CSS, como pseudo-classes (`:hover`), pseudo-elementos (`::first-letter`) e seletores combinadores avançados.

## 📂 Estrutura de Arquivos

```text
.
├── index.html          # Arquivo principal com a estrutura e conteúdo didático
└── assets/
    └── css/
        └── style.css   # Arquivo de estilos responsável pelo layout e regras visuais
```

## 🛠️ Tecnologias Utilizadas

- **HTML5:**
  - Tags semânticas (`<header>`, `<main>`, `<section>`, `<article>`)
  - Tabelas e listas estruturadas (`<table>`, `<ul>`, `<ol>`)
  - Uso de blocos de código (`<pre>`, `<code>`)
- **CSS3:**
  - Importação de fontes e estilização de tipografia
  - Seletores de Tag, Classe (`.`), ID (`#`) e Universal (`*`)
  - Pseudo-elementos (`::first-letter`) para efeitos tipográficos (*drop cap*)
  - Pseudo-classes (`:hover`) e combinadores adjacentes (`+`) para efeitos interativos

## 💡 Conceitos Aplicados

### 🟢 HTML
- **Estruturação Semântica:** Separação lógica entre seções, artigos e cabeçalhos.
- **Formatação de Conteúdo:** Utilização de marcações fortes (`<strong>`), parágrafos e listas encadeadas.
- **Tabelas Explicativas:** Organização de conteúdo de síntese utilizando `<thead>`, `<tbody>` e células formatadas.

### 🔵 CSS
- **Reset Básico e Tipografia:** Ajustes globais de margem, espaçamento e definição de famílias de fontes.
- **Identidade Visual Temática:** Uso de paleta de cores distinta para diferenciar a seção de HTML (tons quentes/amarelados) da seção de CSS (tons frios/azulados).
- **Interatividade Visual:** Animações simples e realces de texto ao passar o mouse (`:hover` e combinadores de seletores).
